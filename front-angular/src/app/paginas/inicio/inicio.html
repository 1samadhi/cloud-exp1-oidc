Pedidos360

Tienda con arquitectura multi nube: la identidad la administra Microsoft Entra ID y los microservicios corren en AWS detras de un API Gateway que valida cada token antes de dejarlo pasar.

Como funciona el acceso

  1. Inicias sesion con Microsoft mediante Authorization Code con PKCE.
  2. Entra ID emite un token firmado con tus roles y permisos.
  3. El API Gateway verifica la firma contra las llaves publicas de Azure.
  4. Cada microservicio vuelve a validar el token por su cuenta.
